- 每个厂商子包在 init() 中调用 asr.RegisterWithMeta(name, New, ProviderMeta{...}) 完成自注册，并提供 DisplayName 与 Fields 列表。
- 客户端结构体统一包含 connMu/resultCh/done/final/finalOnce/textMu/lastText 等同步原语，SendAudio 用互斥锁保护连接写入，ReceiveLoop 负责关闭 resultCh/done/final。
- providerCfg 使用 map[string]interface{} 传参，通过类型断言读取键值（如 app_id/api_key），缺失时回退到默认常量或报错。
- Result 的 IsFinal 由业务语义判定（如 header.Status==2、flags 位、utterances[].Definite），并通过 sync.Once 仅关闭 final chan 一次。
- 错误通过 Result.Error 字段经 Results() 通道上报，而非直接返回 error，保持 SendAudio/ReceiveLoop 的异步一致性。
