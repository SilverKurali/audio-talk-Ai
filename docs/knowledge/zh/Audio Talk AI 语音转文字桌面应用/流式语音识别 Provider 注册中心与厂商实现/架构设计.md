- 核心协议集中在 asr.go：`Client` 接口（Connect/SendAudio/Results/Done/Final/LastText/ReceiveLoop/Close）、`Result`（Text/IsFinal/Error）与 `Common`（Language/Hotwords），所有厂商必须遵循该异步通道协议。
- 注册中心 registry.go 维护全局 `map[string]Factory` 与 `map[string]ProviderMeta`，通过 `RegisterWithMeta` 同时绑定工厂函数与 UI 配置元数据；`NewClient` 按名称查找并构造实例；`Providers()`/`AllProviderMeta()`/`KnownFieldKeys()` 暴露给上层用于动态发现与配置校验。
- metadata.go 定义 `FieldDef`（text/secret/select 三类字段）与 `ProviderMeta`，供 TUI/WebUI 渲染配置表单。
- drivers/drivers.go 以空白导入聚合所有厂商包，触发各自的 `init()` 完成自注册，新增厂商只需在此加一行 import。
- 每个厂商位于独立子包（doubao/mimoasr/openairealtime/openaiwhisper/xfyun*），各自实现 `New(common, providerCfg, logger)` 返回 `asr.Client`，并在 `init()` 中调用 `asr.RegisterWithMeta` 完成注册。
- 依赖方向单向：厂商子包 → asr 核心接口 + 第三方 WS SDK（coder/websocket、gorilla/websocket），核心包不反向依赖任何厂商。
