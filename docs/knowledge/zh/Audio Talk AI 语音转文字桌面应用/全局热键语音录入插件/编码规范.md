- 所有跨 goroutine 访问的共享字段都通过 `p.mu` 加锁后再读取，并在需要发布状态时调用 `publishStatusLocked` 而非直接修改 TUI 结构体。
- 平台相关实现通过 Go build tag 拆分（`linux`/`windows`/`darwin && cgo`），提供相同签名函数（`pickCommandWithDevice`、`errNoBackend`、`ListDevices`）供 recorder.go 统一调用。
- 外部命令捕获采用 `firstFound` 候选列表 + `exec.LookPath` 探测，失败时返回带安装提示的错误信息，便于用户排查。
- 异步资源清理统一用 `detachRecordingLocked` 剥离会话句柄，再在独立 goroutine 中执行 `finishRecordingSession`，避免阻塞热键处理线程。
- 错误状态设置使用 `publishErrorLocked` 配合 `errorUntil` 定时器自动过期，并提供 R 热键手动重试，避免 UI 长时间卡死。
- 新增 ASR Provider 仅需在对应包 init() 中注册工厂+元数据，并在 `asr/drivers/drivers.go` 添加一行空白 import，无需改动本模块或其他上层组件。
