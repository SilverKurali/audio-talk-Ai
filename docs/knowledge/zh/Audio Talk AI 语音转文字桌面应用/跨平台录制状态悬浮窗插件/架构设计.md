模块采用「纯 Go 编排 + 平台后端」分层：
- `overlay.go` 定义 `backend` 接口与 `Plugin`，负责从 `voice.TUIStatus()` 读取状态、计算标签与颜色、通过 ticker 驱动 Show/Hide/Refresh，并暴露标准插件生命周期 `Init/Start/Stop`。
- Linux 下由 `backend_linux.go` 的 `newBackend` 根据环境变量自动选择 Wayland 或 X11；Wayland 实现位于 `backend_wayland.go`，使用 cgo 直接调用 libwayland-client 并通过 `wlr-layer-shell-unstable-v1` 协议创建 overlay surface，像素缓冲经 shm pool 提交；X11 实现位于 `backend_x11.go`，基于 Xlib/Xrender 创建无边框窗口，支持 ARGB 合成路径与非合成 Shape 回退路径。
- macOS 下 `backend_darwin.go` 启动子进程作为 helper，通过 stdin JSON 命令 (`show/hide/close`) 控制由 `overlay_darwin.m` + `overlay_darwin.h` 实现的 AppKit 悬浮层；`helper_darwin.go` 提供 `RunHelper` 入口供主程序以 `--overlay-helper` 参数复用同一二进制。
- `protocols/` 目录存放 wlr-layer-shell 与 xdg-shell 的 XML 及由 `wayland-scanner` 生成的 C 客户端头/源文件，作为 Wayland 后端的协议绑定。
- 渲染逻辑（圆角矩形覆盖度采样、5×7 位图字体、抗锯齿点阵）在 Wayland 与 X11 后端中各自实现一份，共享 `glyphs` 字模表；`*_stub.go` 为不支持的平台提供空实现，使包可在无 GUI 环境编译。
