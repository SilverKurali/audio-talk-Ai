- 每个平台后端以 `//go:build linux && !no_x11` / `darwin && cgo` / `stub` 等构建标签隔离，统一暴露同名的 `newBackend(cfg) (backend, error)` 工厂函数。
- 所有平台后端均实现 `Show/Hide/Close/Refresh` 四个方法，并在内部用互斥锁保护对底层句柄的并发访问。
- 像素绘制采用统一的 `rgba{r,g,b,a}` 结构体与 `setPixel/blendPixel/fillCircleAA/drawText` 模式，先写内存再提交到 Wayland shm 或 XImage。
- 文本渲染使用内嵌的 5×7 位图字模表 `glyphs`，通过 `bitmapTextWidth` 计算宽度并按 scale 放大绘制，避免依赖外部字体库。
