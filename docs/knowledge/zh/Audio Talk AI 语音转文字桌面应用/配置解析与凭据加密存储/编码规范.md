- 所有敏感字段（AppKey/AccessKey/ApiKey/AppID/ApiSecret/DWA/Voice.*Key 等）统一以 `enc:` 前缀标记已加密值，空串视为明文跳过加解密。
- 对 ASR provider 的配置采用“已知字段 + Extra map”双轨模式：`knownASRKeys` 白名单 + `typedFieldMap()` 指针映射，未知键自动落入 `Extra`，并通过 `Get/Set`/`ProviderCfgMap` 透明访问。
- 磁盘 I/O 操作一律以 `0600` 权限创建 key 和 config 文件，确保仅当前用户可读（Windows 上权限位无实际意义，依赖 %APPDATA% 用户目录 ACL 保护）。
- 涉及密文的持久化路径遵循 XDG 规范：优先 `$XDG_CONFIG_HOME/audio-talk-ai`，回退到 `~/.config/audio-talk-ai`；Windows 上优先 `%APPDATA%\audio-talk-ai`（os.UserConfigDir），并在 `FindConfig` 与 `keyDir` 中保持一致的候选顺序。
- 保存时通过 `cloneForSave` 深拷贝后再 `encryptSecrets`，避免修改运行中的明文 Config，保持内存态与磁盘态解耦。
