- 客户端与服务端通过统一的 framed 协议（1 字节 type + 4 字节 BigEndian length + payload）进行序列化，由 `readFrame`/`writeFrame` 集中编解码。
- 会话状态以 `.sock` + 同名 `.json` 文件对形式落盘，元数据统一走 `WriteMeta`/`ReadMeta`，清理时成对删除。
- 对外暴露的入口函数（`RunServer`、`RunServerWithRestart`、`Attach`、`PickAndAttach`、`DetachSession`）均为无状态包级函数，内部再构造对象或 goroutine 执行具体逻辑。
- 错误返回一律使用 `fmt.Errorf("session: ...", err)` 前缀，便于上层区分来源。
