模块按「公共 API + 平台 Provider 实现」分层：
- 公共层（hotkey.go / keycodes.go / provider.go / registry.go / tracker.go）定义统一类型 `Modifier`、`KeyCode`、`Combo`、`Event` 以及 `Provider` 接口和 `Registry` 多路复用器；`KeyStateTracker` 是纯 Go 的状态机，负责从底层 KeyDown/KeyUp 序列中合成三种事件（KeyDown/KeyUp/KeyPress），并处理修饰键独占、功能键独占等边界情况。
- 平台层通过 Go build tag 选择具体实现：`provider_windows.go`（`//go:build windows`，WH_KEYBOARD_LL + GetMessage 消息泵）、`provider_darwin.go`（`//go:build darwin`，CGEventTap + C pipe 桥接）、`provider_linux_x11.go`（`//go:build linux && !no_x11`，XGrabKey + X event loop）、`provider_linux_wayland.go`（`//go:build linux`，evdev `/dev/input/event*`）、`provider_mock.go`（测试用）。每个文件都导出同名 `NewProvider()` 函数供上层构造。
- `registry.go` 持有 `Provider`，为每个 Combo 保存 Provider 返回的事件 channel（各平台实现均为 32 缓冲），并在 `Start(ctx)` 后启动 per-handler dispatch goroutine 将事件分发给回调；`Unregister` 关闭对应 channel 以通知消费者。
- 依赖方向单向：platform provider → tracker → 公共类型；registry 仅依赖 Provider 接口，不感知具体平台。
