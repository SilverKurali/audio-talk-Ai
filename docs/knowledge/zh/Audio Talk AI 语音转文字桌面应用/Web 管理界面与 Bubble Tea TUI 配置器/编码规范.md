- HTTP 响应统一通过 `writeJSON(w, code, v)` 设置 `Content-Type: application/json` 后再写入，错误路径返回 `{"error": ...}` 结构。
- 配置变更处理器在 `config.Save` 成功后总是调用 `s.engine.ReloadConfig(&cfg)` 触发热重载，保证 WebUI 与 TUI 的配置一致性。
- TUI 字段采用声明式 `field{label,key,help,fType,...}` 切片 + `rebuildFields` 从 `asr.FieldDef` 元数据动态生成，新增 ASR 类型无需修改 UI 代码。
- 选择型字段在显示层使用 `Labels`，落盘时通过 `displayToConfig` 转回 `Options` 值，避免用户可见标签与存储值耦合。
